# VitalityChems GitBook

> **Status: published 2026-10-05 (commit 98fa6c7) — approved by Gitbook Moderator and Father**

## Purpose

This GitBook is the **intake and documentation home** for Collin Keane's ("Father") mesh of AI agents.

Work from agents lands here first. It is organized by **Gitbook/ Cordnation**, reviewed by **Gitbook Moderator**, digested to Father by **Command Center**, and only then (after Father's explicit approval) pushed privately to GitHub via Replit. Merges require Father's separate explicit `merge`.

This space is for drafting, filing, and tracking documentation before it reaches Origin / GitHub. It is not a substitution for the coordination board or for build/push lanes.

## What belongs here

- Agent role descriptions and lane boundaries
- Intake submissions (drafts awaiting review)
- Mesh flow and standing rules
- Review handoff records and status definitions

## What does not belong here

- Secrets, credentials, or tokens
- Crypto / money / store work
- Uncensoring tools or surveillance of real people
- Changes to `TESSERA_ENABLE_*` flags (they stay `0`)
- New coordination boards (use only GitHub `vitalitychems-dot/tessera-coordination` issue **#4**)
