# slitlab RESULTS (2026-10-13, simulation, numpy 2.5.3, seed 7)
Every number comes from `python3 slitlab.py` and is saved in results.json. Tests: `python3 test_slitlab.py` (10/10 pass).

1. **Double slit + which-path.** Claim: interference needs path indistinguishability. Test: Fraunhofer 2-slit pattern (500 nm light, d=50 µm, a=10 µm), with visibility measured on the envelope-normalized pattern. Measured: V=1.000 coherent; V=0.000 with full which-path detection; V(D)=0.866 / 0.436 at D=0.5 / 0.9, matching V=√(1−D²). **Confirmed.**
2. **Continuous slit phase knob.** Claim: phase is an analog (non-binary) control. Test: MZI port I=cos²(φ/2), plus a 16-element analog dot product with 0.02 rad phase jitter and shot noise (10⁴ photons per element), 200 trials. Measured: mean relative error 0.72% (p95 1.83%), about 7.1 effective bits. **Confirmed (simulation only):** it's analog, but with only about 7 bits of precision.
3. **"Mirror the best option back" = amplitude amplification.** Test: Grover search on qlab.qsim, N=4…4096. Measured: N=1024 needs 25 queries for p=0.9995, while classical search needs 1024 for the same p (512 on average). N=4096 needs 50 queries for p=0.9999. The quadratic speedup √N holds, and it isn't exponential. **Confirmed (simulation only).**
4. **MZI logic gates from continuous phases.** Test: NOT, XOR (scale π), AND (scale 0.4π) and OR (bias π/3, scale π/3), with output thresholded at 0.5. Measured: all four truth tables are correct. The gates tolerate a common phase error of ±0.314 rad. **Confirmed (simulation only).**
5. **No-signaling (the "two places at once" channel).** Test: on a Bell pair, Alice sweeps her measurement angle over 9 settings. Measured: Bob's P(0)=0.5 at every setting (max deviation 0.0), and the sampled mutual information is 6×10⁻⁷ bits (sampling noise, 200k shots). **Disproved:** you can't send a usable signal to two places at once, and no choice of slit setting carries information.
6. **N-slit grating as a superposition encoder.** Measured: peak intensity is N² for N=2…32 (constructive interference), and peak width is 1/N. Capacity: N slits give an N-dimensional mode space (log₂N qubit-equivalent), or N·3 bits per shot classically at 8 phase levels. **Confirmed (simulation only):** capacity grows linearly with the number of slits, not exponentially.
7. **Optical analog optimizer (phase-annealed Max-Cut, 8 nodes).** Test: 200 seeds, compared with random search at an equal number of evaluations. Measured hit rate at 10/30/100 evaluations: optical 0.125/0.36/0.77 vs random 0.12/0.37/0.79. **Disproved (no advantage at this size).**
8. **5D crystal memory capacity.** Test: bits per voxel = log₂(orientation levels × retardance levels), with Gaussian readout noise (σ 4° in angle, 0.04 in retardance). Measured symbol error: 4×4 levels → 4 bits at 0.115%; 8×4 → 5 bits at 0.64%; 8×8 → 6 bits at 10.9% (too noisy). At an *assumed* voxel pitch of 0.5×0.5×2 µm, 4 bits per voxel gives about 1.0 TB/cm³ raw. Published: Zhang, Gecevičius, Beresna, Kazansky, *Phys. Rev. Lett.* 112, 033901 (2014), with a theoretical ~360 TB per disc; Microsoft Project Silica (Anderson et al., SOSP 2023). The pitch is my assumption, not a published figure. **Simulation only.**
9. **Tessera memory → 5D voxels.** Test: 200 palace chunks (320,516 B), zlib-compressed to 89,543 B (3.58×), Gray-coded into 4-bit voxels (179k raw, 313k with Hamming(7,4) plus interleaving). Measured at σ 4° / 0.04: raw BER 3.6×10⁻⁴ → 1.4×10⁻⁶ with ECC, and 100% of the 2 KB blocks recovered exactly. One compressed archive fails on a single residual bit, so the data has to be stored in blocks. At σ 8° / 0.07: BER 1.5% → 0.18%, and only 1.3% of blocks recovered, so a stronger code (LDPC/RS) is needed. **Simulation only.**
10. **Interference search over palace memory.** Test: Grover search over 1024 real palace chunk paths, with the target set to INVENTIONS.md. Measured: 25 oracle queries with p=0.9995, against 512.5 expected classically (about 20× fewer queries). Caveat: on our classical box, a statevector simulation costs O(N) per step, so this gives **no real speedup** without quantum hardware. The memory palace's FTS index (~2 ms) is the fastest option here. **Simulation only.**
