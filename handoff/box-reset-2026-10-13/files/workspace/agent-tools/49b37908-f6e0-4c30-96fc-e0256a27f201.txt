+# SETUP-FATHER: steps only Father can do
+
+Why: every agent pushes and comments as `vitalitychems-dot`, so CODEOWNERS reviews, `FATHER APPROVED` comments and PASS comments can all be forged (Moderator and Security, Gitbook #71). `moderator-lock` therefore **fails closed** until the steps below are done. Agents must not do any of them.
+
+## 1. Separate Father from the agents
+1. Create a **second, Father-only GitHub account** (for example `collin-keane`). It becomes the only admin and CODEOWNER. Enable 2FA on it.
+2. Repo **Settings → Secrets and variables → Actions → Variables** on TESSERA and Gitbook:
+   - `FATHER_LOGIN` = that account's login. It must be different from `vitalitychems-dot`; otherwise the lock stays closed.
+   - `AGENT_LOGINS` = `vitalitychems-dot` (comma-separated if there are more).
+3. Change `@vitalitychems-dot` to the Father-only login in `/CODEOWNERS` (Gitbook) and `/.github/CODEOWNERS` (TESSERA), from the Father account.
+4. Downgrade `vitalitychems-dot` to **Write** (not Admin) on both repos, or move the agents to the Apps in step 2 and revoke the PAT on the box.
+5. **Keep the owner token off the box.** Don't run `gh auth login` as the Father account on the shared box. Revoke any owner PAT already stored there (Settings → Developer settings → Tokens).
+
+## 2. Create 3 GitHub Apps (one identity per gate)
+For each of **Tessera Moderator**, **Tessera Security** and **Tessera Build** (Settings → Developer settings → GitHub Apps → New):
+- Homepage: the repo URL. Webhook: off.
+- Permissions: **Checks: Read & write**, Contents: Read, Pull requests: Read, Metadata: Read. Nothing else.
+- Install it on **TESSERA and Gitbook only**.
+- Note the **App ID** and set repo variables `MODERATOR_APP_ID`, `SECURITY_APP_ID`, `BUILD_APP_ID`.
+- Generate a private key and give each key **only to that gate's runner/agent**, never to the shared box. The gate posts its PASS/FAIL as a **check run** on the head SHA. PASS comments are ignored.
+
+## 3. Branch protection on `main` (both repos), Settings → Rules → Rulesets
+Draft. Father applies it; agents do not.
+- Target: default branch. Enforcement: Active. **Bypass list: empty** (no admin bypass).
+- Require a pull request before merging:
+  - required approvals: 1;
+  - **Require review from Code Owners**: on;
+  - **Dismiss stale approvals when new commits are pushed**: on;
+  - **Require approval of the most recent reviewable push**: on.
+- Require status checks to pass, with **Require branches to be up to date** on:
+  - `moderator-lock / collect` (GitHub Actions);
+  - the check names posted by the **Tessera Moderator**, **Tessera Security** and **Tessera Build** apps, each pinned to its app as the "expected source";
+  - (TESSERA only: `CI / validate`.)
+- Block force pushes. Restrict deletions. Require linear history.
+- Optional: merge queue with a group size of 1 (Rick #14).
+
+## 4. Kill switch
+`gate/MERGE_BOT_ENABLED` (locked path) holds `0`. A merge bot may merge only when it reads exactly `1`; a missing file or any other value means off. Only Father changes it, through a code-owner-reviewed PR.
+
+## 5. Optional
+- `GITBOOK_LOG_TOKEN` secret on TESSERA (a fine-grained token, Gitbook only, Issues: write) lets `meta-loop` mirror to Gitbook #67.
+- `TESSERA_WORKER=1` turns on the in-runner fixer. `TESSERA_MESH_RUNNERS=1` allows opt-in mesh runners. Both default to 0.
+- Worker PRs opened with `GITHUB_TOKEN` don't trigger `pull_request` workflows (a GitHub rule). For gates to run on them, the worker must push with the **Build App** token. Until then those PRs stay unchecked and can't merge (fail closed).

+#!/usr/bin/env node
+// moderator-lock: fail-closed path lock + rule checks + gate-identity verification.
+// Pure function `evaluate(input)`; CLI reads a JSON input file (built by the workflow from the GitHub API).
+// Owned by Father via CODEOWNERS. Agents may not edit this file.
+import { readFileSync } from "node:fs";
+import { fileURLToPath } from "node:url";
+
+export function globToRegExp(glob) {
+  let g = glob.trim();
+  const anchored = g.startsWith("/");
+  if (anchored) g = g.slice(1);
+  if (g.endsWith("/")) g += "**";
+  let re = "";
+  for (let i = 0; i < g.length; i++) {
+    const c = g[i];
+    if (c === "*" && g[i + 1] === "*") { re += ".*"; i++; if (g[i + 1] === "/") i++; }
+    else if (c === "*") re += "[^/]*";
+    else if (c === "?") re += "[^/]";
+    else re += c.replace(/[.+^${}()|[\]\\]/g, "\\$&");
+  }
+  // Unanchored patterns without a slash match at any depth (CODEOWNERS semantics).
+  const prefix = anchored || g.includes("/") ? "^" : "^(?:.*/)?";
+  return new RegExp(prefix + re + "(?:/.*)?$");
+}
+
+export function parseLockList(text) {
+  return text.split("\n").map((l) => l.replace(/#.*/, "").trim()).filter(Boolean);
+}
+
+export function lockedHits(files, patterns) {
+  const res = patterns.map((p) => [p, globToRegExp(p)]);
+  return files.filter((f) => res.some(([, r]) => r.test(f.filename ?? f)))
+    .map((f) => f.filename ?? f);
+}
+
+const ENABLE_ON = /^\+.*TESSERA_ENABLE_[A-Z0-9_]+["']?\s*[:=]\s*["']?(1|true|on|yes)\b/im;
+const NEW_FLAG_ON = /^\+.*TESSERA_[A-Z0-9_]+["']?\s*[:=]\s*["']?(1|true|on|yes)["']?\s*,?\s*$/im;
+const SECRETISH = /^\+.*(ghp_[A-Za-z0-9]{20,}|github_pat_[A-Za-z0-9_]{20,}|sk-[A-Za-z0-9]{20,}|-----BEGIN [A-Z ]*PRIVATE KEY-----|moltbook_sk_[A-Za-z0-9]{8,})/m;
+const FORBIDDEN_PATH = [REDACTED-PATH]
+
+export function evaluate(input) {
+  const cfg = { maxLines: 400, maxFiles: 10, ...(input.config ?? {}) };
+  const reasons = [];
+  const notes = [];
+  const files = input.files ?? [];
+  const head = input.headSha;
+  const agentLogins = new Set((input.agentLogins ?? ["vitalitychems-dot"]).map((s) => s.toLowerCase()));
+
+  // Rule 1: locked paths. Only an unforgeable Father approval unlocks.
+  const hits = lockedHits(files, input.lockedPatterns ?? []);
+  if (hits.length) {
+    const father = (input.fatherLogin ?? "").toLowerCase();
+    if (!father) {
+      reasons.push(`locked paths touched (${hits.join(", ")}); FATHER_LOGIN not configured -> fail closed`);
+    } else if (agentLogins.has(father)) {
+      reasons.push(`locked paths touched (${hits.join(", ")}); FATHER_LOGIN '${father}' is also the agent account, so its reviews/comments can be forged -> fail closed`);
+    } else {
+      const ok = (input.reviews ?? []).some((r) =>
+        (r.user?.login ?? "").toLowerCase() === father && r.state === "APPROVED" && r.commit_id === head);
+      if (!ok) reasons.push(`locked paths touched (${hits.join(", ")}); no APPROVED review from ${father} on head ${head}`);
+      else notes.push(`locked paths approved by ${father} review on ${head}`);
+    }
+    // Comments are never accepted: any agent can post "FATHER APPROVED <sha>" as the shared account.
+    if ((input.comments ?? []).some((c) => /FATHER APPROVED/i.test(c.body ?? "")))
+      notes.push("ignored 'FATHER APPROVED' comment(s): comments are forgeable by the shared account");
+  }
+
+  // Rule 1: flags, secrets, forbidden paths, deletions.
+  const patch = files.map((f) => f.patch ?? "").join("\n");
+  if (ENABLE_ON.test(patch)) reasons.push("diff turns on a TESSERA_ENABLE_* flag");
+  else if (NEW_FLAG_ON.test(patch)) reasons.push("diff adds a TESSERA_* flag that does not default to 0");
+  if (SECRETISH.test(patch)) reasons.push("diff adds something that looks like a secret");
+  const forb = files.filter((f) => FORBIDDEN_PATH.test(f.filename)).map((f) => f.filename);
+  if (forb.length) reasons.push(`touches wallet/payment/crypto/vault paths: ${forb.join(", ")}`);
+  const removed = files.filter((f) => f.status === "removed").map((f) => f.filename);
+  if (removed.length) reasons.push(`deletes files (needs Father-approved delete list): ${removed.join(", ")}`);
+
+  // Rule 3: synthetic-only evidence never counts as a win.
+  const body = input.prBody ?? "";
+  if (/synthetic[- ]only/i.test(body) && /\b(win|wins|improv\w*|kept|faster|better)\b/i.test(body))
+    reasons.push("claims a win on synthetic-only evidence (rule 3)");
+
+  // Rule 6: size cap.
+  const lines = files.reduce((n, f) => n + (f.additions ?? 0) + (f.deletions ?? 0), 0);
+  if (files.length > cfg.maxFiles || lines > cfg.maxLines)
+    reasons.push(`size cap: ${files.length} files / ${lines} lines (cap ${cfg.maxFiles} / ${cfg.maxLines}); split the PR`);
+
+  // Rule 2: a gate cannot pass its own PR.
+  const authors = new Set([(input.prAuthor ?? "").toLowerCase(), ...(input.commitAuthors ?? []).map((s) => s.toLowerCase())]);
+  return { lock: { pass: reasons.length === 0, reasons, notes, lockedHits: hits, lines, files: files.length }, gates: verifyGates(input, authors) };
+}
+
+// Gate identity: only check runs posted by the configured per-gate GitHub App ids count.
+export function verifyGates(input, authors = new Set()) {
+  const out = { pass: true, reasons: [] };
+  const apps = input.gateApps ?? {};
+  for (const gate of ["moderator", "security", "build"]) {
+    const id = Number(apps[gate]);
+    if (!id) { out.pass = false; out.reasons.push(`${gate}: app id not configured -> fail closed`); continue; }
+    const runs = (input.checkRuns ?? []).filter((r) => Number(r.app?.id) === id);
+    const slug = (runs[0]?.app?.slug ?? "").toLowerCase();
+    if (slug && (authors.has(slug) || authors.has(`${slug}[bot]`))) { out.pass = false; out.reasons.push(`${gate}: gate app authored this PR; cannot self-pass`); continue; }
+    const good = runs.find((r) => r.head_sha === input.headSha && r.conclusion === "success");
+    if (!good) {
+      out.pass = false;
+      out.reasons.push(runs.some((r) => r.conclusion === "success")
+        ? `${gate}: PASS is stale (not on head ${input.headSha})`
+        : `${gate}: no successful check run from app ${id} on head`);
+    }
+  }
+  // PASS comments are never evidence.
+  return out;
+}
+
+if (process.argv[1] === fileURLToPath(import.meta.url)) {
+  const [mode = "lock", file] = process.argv.slice(2);
+  const input = JSON.parse(readFileSync(file, "utf8"));
+  const r = evaluate(input);
+  const part = mode === "gates" ? r.gates : r.lock;
+  console.log(JSON.stringify(part, null, 2));
+  process.exit(part.pass ? 0 : 1);
+}

+// Kill switch (Security #71 item 6): gate/MERGE_BOT_ENABLED on a locked path. Only the exact value "1" enables.
+// Missing, empty or unknown values mean OFF.
+export function mergeBotEnabled(text) { return typeof text === "string" && text.trim() === "1"; }

+

+Only Father edits this file. Tessera and the agents cannot. `gate/moderator-lock.mjs` enforces these rules as code.
+
+1. **Reject the PR** if it:
+   - touches a locked path (`gate/locked-paths.txt`): gate rules, gate scripts, `.github/workflows`, CODEOWNERS, branch protection or rulesets, agent prompts, policy files;
+   - flips `TESSERA_ENABLE_*`, or adds a flag that doesn't default to 0;
+   - adds a secret, deletes data or a repo, or rewrites history;
+   - touches wallet, payment or 1T paths;
+   - works in a repo other than TESSERA or Gitbook.
+2. **Author ≠ approver.** The author is the PR opener plus everyone named in its commits. A gate can't pass its own PR.
+3. **Proof:** before/after numbers on fixtures the author didn't build. Wins backed only by synthetic data don't count. Any score drop beyond noise is a FAIL.
+4. A claim that can't be verified is marked **REPORTED** and is never evidence for a PASS.
+5. A PASS is tied to the exact head SHA. Any new push makes it stale.
+6. **Size cap:** 400 changed lines and 10 files (Father sets these). Anything bigger gets split.
+7. Hard limits beat "no human in loop": no wallets or payments, no [REDACTED-PATH] no deletes, no history rewrites, no ENABLE flips.
+
+## Identity (blocking flaw from #71)
+Every agent pushes as `vitalitychems-dot`. So:
+- A `FATHER APPROVED <sha>` **comment never counts**: any agent can post it.
+- A review only counts when it comes from `FATHER_LOGIN`, an account that is **not** the agent account, and is APPROVED on the head SHA.
+- A gate PASS only counts as a **check run from the gate's own GitHub App** (repo variables `MODERATOR_APP_ID`, `SECURITY_APP_ID`, `BUILD_APP_ID`). PASS comments never count.
+- If any of these isn't configured, the check **fails closed**.
