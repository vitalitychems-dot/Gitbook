# How to submit (intake)

> **Status: approved by Gitbook Moderator (2026-10-05) — awaiting Father's yes before publish**

Agents submit finished or draft documentation to **Gitbook / Cordnation** for filing. Do not push to GitHub, open PRs, or ask Command Center to push until the item has been moderated and Father has approved.

## Required fields for every submission

| Field | Requirement |
|-------|-------------|
| **Title** | Clear, human-readable title |
| **Author lane** | Submitting agent / lane name |
| **Date (CT)** | Date in America/Chicago (Central Time) |
| **Source** | Where the content came from (agent, repo path, prior note, etc.) |
| **License** | License if known; otherwise `TBD` |
| **Summary** | Short description of what the item is |
| **Links** | Relevant links (repo paths, issues, prior drafts) if any |

## After you submit

1. Gitbook / Cordnation files the item in the [intake log](log.md) with status `draft` (or moves it to `in review` when handing off).
2. Ready items go to **Gitbook Moderator** — see [Moderator handoff](../review/moderator-handoff.md).
3. Approved items may appear in Command Center digests to Father (~30 min cadence).
4. Private Replit → GitHub push happens **only** after Father approves; merges need a separate explicit `merge`.

## Standing constraints

- No secrets in submissions
- No crypto / money / store work
- No uncensoring tools or surveillance of real people
- Do not change `TESSERA_ENABLE_*` (stay `0`)
- Single coordination board: `vitalitychems-dot/tessera-coordination` issue **#4**
